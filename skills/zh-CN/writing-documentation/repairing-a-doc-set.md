# 修复一组文档

> 本文中全大写的规范关键词 MUST、MUST NOT、REQUIRED、SHALL、SHALL NOT、SHOULD、SHOULD NOT、RECOMMENDED、MAY、OPTIONAL 按 BCP 14（RFC 2119、RFC 8174）解释，且仅在全大写时具有规范含义。

## 1. 先将修复纳入范围

- 重组没有入口、有多个入口或入口与磁盘内容不符的文档组前 → 你 MUST 告知用户发现的情况（文档组、具体缺陷和修复涉及的内容），并取得同意。

## 2. 阅读整组文档

- 写表格中的任何一行前 → 你 MUST 阅读文档组中的每份文档。

## 3. 盘点

- 无法确定什么任务会引导读者阅读某份文档 → 你 MUST NOT 编造任务信号来容纳它。

## 4. 核对每条路径

- 编写路径时 → 你 MUST 以入口所在目录为基准解析并打开路径。
