# 自我开脱 — 两个方向

> 本文中全大写的规范关键词 MUST、MUST NOT、REQUIRED、SHALL、SHALL NOT、SHOULD、SHOULD NOT、RECOMMENDED、MAY、OPTIONAL 按 BCP 14（RFC 2119、RFC 8174）解释，且仅在全大写时具有规范含义。

## 为跳过适用技能找理由

出现下表任一想法 → 你 MUST 停下，先检查适用技能：

| 想法 | 命令 |
|---------|---------|
| “这只是个简单问题” | 停下，先检查适用技能。 |
| “我得先了解更多上下文” | 停下，先检查适用技能。 |
| “让我先看看代码” | 停下，先检查适用技能。 |
| “这事太小，用不上技能” | 停下，先检查适用技能。 |
| “这个我已经知道了” | 停下，先检查适用技能。 |
| “我先做这一件事” | 停下，先检查适用技能。 |
| “这里用技能太重了” | 停下，先检查适用技能。 |

## 用户指令

用户陈述任务目标，且未明确指示跳过适用技能 → 你 MUST 应用技能。
