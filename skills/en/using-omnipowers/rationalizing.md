# Rationalizations — both directions

> Normative keywords — MUST, MUST NOT — are used as defined in BCP 14 (RFC 2119, RFC 8174), and only when capitalized.

## Talking yourself out of a skill that governs

On any thought in the following table → you MUST stop and check for an applicable skill first:

| Thought | Command |
|---------|---------|
| "This is just a simple question" | Stop and check for an applicable skill first. |
| "I need more context first" | Stop and check for an applicable skill first. |
| "Let me look at the code first" | Stop and check for an applicable skill first. |
| "This is too small to need a skill" | Stop and check for an applicable skill first. |
| "I already know this" | Stop and check for an applicable skill first. |
| "I'll just do this one thing first" | Stop and check for an applicable skill first. |
| "The skill is overkill here" | Stop and check for an applicable skill first. |

## User instructions

The user states a task goal without explicitly telling you to skip the applicable skill → you MUST apply the skill.
